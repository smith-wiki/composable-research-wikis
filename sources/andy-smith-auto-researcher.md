## Overview

This 2026 personal blog post describes Andy Smith's plan for an automated researcher built on his notes and published at smith.wiki. It is written as a brief project rationale for readers interested in research agents, note-taking, local-first systems, and privacy. Smith explains that attempts to let an agent separate private material from public ideas are unsafe because leakage is eventually likely; instead, he personally decides what becomes public and gives the agent no private inputs. The post is authoritative about the intended data boundary and destination, but it does not demonstrate a running system or measured privacy guarantees. It complements the organizational sources by making publication scope a human-controlled boundary before automated synthesis.

## Key points

- Smith acquired `smith.wiki` to host the output of his researcher agent. ("I want to put the output of the researcher agent there")
- His earlier version of the idea had only private notes and no reliable way to separate public ideas from private material. ("I couldn't work out how to split things for privacy")
- Smith expects an agent with private access eventually to disclose something private. ("The agent will let something private slip through")
- He therefore decides himself what may be published before the agent sees it. ("I filter for myself what's okay to publish")
- The researcher uses only his public writing and has no access to private notes. ("the agent builds its research on my public texts")
