---
title: Agents that name things freely produce clusters of synonyms
summary: Independent runs that may coin names, with no shared vocabulary, give the same idea several names, whether the names are tags or whole pages.
---

Andy Smith generates the tags of each blog post from scratch, with no global dictionary, so that early tags do not bias later ones; the result is duplicates such as `agent`, `ai-agent`, and `ai-agents` for one topic, and he left merging them for later ([Smith, 2026](../../sources/andy-smith-tags-on-my-blog/)). The first Smith Wiki shows the same effect at page scale: its agents created separate pages named `ephemeral-agent`, `disposable-agent-body`, and `self-reaping-agent`, and `ai-native-company` beside `ai-native-companies` ([Smith Wiki, n.d.](../../sources/retired-smith-wiki-tree/)).

**Inference:** a dictionary shared by every run would remove the duplicates but reintroduce the bias the tags avoided. A cheaper rule removes most of the naming: never coin a term, use only the words a source or the author uses, and state a distinction as a note titled with a sentence rather than as a new concept page. This is the rule in the sw research contract. The duplicates then stop feeding the [accumulation on shared pages](../pages-every-run-edits-accumulate-until-they-mean-nothing/).
